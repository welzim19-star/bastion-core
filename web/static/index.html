🌐 Controle de Acesso Web na Rede Local (Administrador sem Senha do Modem da Provedora)

Como a provedora bloqueia a senha da ONT principal (192.168.1.1), veja como funciona o bloqueio de internet/web na sua topologia atual:

1️⃣ Bloqueio Web & Host no Servidor Bastion (Ativo)

Qualquer IP bloqueado acima recebe HTTP 403 Forbidden imediato em todas as portas web deste PC e tem pacotes cortados (Entrada + Saída) no Windows Firewall. Clique em ⚡ Ativar no Kernel (UAC Admin) para gravar a regra no Windows Defender.

2️⃣ Roteador / Mesh Secundário Detectado (192.168.1.128 / .10)

O Bastion detectou os Access Points 192.168.1.128 e 192.168.1.10 na sua rede! Diferente do modem da provedora (192.168.1.1), o roteador/Mesh secundário permite bloquear a internet (WAN) de qualquer celular pelo MAC/IP no Controle Parental.

↗ Abrir AP 192.168.1.128 ↗ Abrir AP 192.168.1.10 ↗ Painel ONT 192.168.1.1
3️⃣ Bloqueio de Sites por IP via DNS Gateway Local

Como celulares no Wi-Fi falam direto com o roteador, para bloquear sites de qualquer aparelho pelo seu PC sem tocar no modem da provedora, basta rodar um DNS Sinkhole (AdGuard Home / Pi-hole) nesta máquina (192.168.1.35) e bloquear o IP do cliente com 1 clique.
